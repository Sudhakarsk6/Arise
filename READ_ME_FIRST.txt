This zip contains the Arise APK build file.

Computer: unzip, then in your GitHub repo choose Add file > Upload files and drag in the
".github" folder (it must keep the path .github/workflows/build.yml). Commit changes.

Phone (folder upload is not possible): in the repo choose Add file > Create new file, type the name
  .github/workflows/build.yml
then open build.yml from this zip in a text app, copy everything, paste it into GitHub, and Commit changes.
