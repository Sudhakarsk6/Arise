# Feature map: files, how it works, how to test, permissions, limitations

| Feature | Files | How it works | Test | Permissions | Limitations |
|---|---|---|---|---|---|
| Splash + logo | `ui.kv` (SplashScreen), `arise/ui_widgets.py` (SpinnerRing), `assets/logo.png`, `main.py` | White screen, logo, animated ring; DB/services load in the background, then the PIN screen. Replace the logo in Settings (path to PNG/JPG) or overwrite `assets/logo.png`. | Run the app | none | The logo is shown on white because it has black parts. |
| Security | `arise/security.py`, `arise/vault.py`, `arise/net.py`, `arise/backup.py` | PBKDF2-hashed PIN + lockout, AES-256-CTR+HMAC vault for API keys, auto-lock, audit log, rate limiter, HTTPS-only network, encrypted backups | `tests/test_security.py` | none | Database file itself is unencrypted; fingerprint unlock cannot open the vault (needs the PIN). |
| Script workspace | `arise/scripts.py`, `arise/sandbox.py` | Import -> validate (AST allow-list) -> auto tests -> diff review -> explicit approval -> hash-pinned run; versions + rollback | `tests/test_scripts.py`, `tests/test_sandbox.py` | per script, declared in `# permissions:` and approved by you | In-process sandbox is a strong filter, not an OS boundary. |
| Automation engine | `arise/adapters/*`, `arise/scripts.py` (scheduler), `arise/automations.py` | Platform adapters (android, windows, macos, linux, ios stub); schedules `daily HH:MM` / `every N min` | `tests/test_scripts.py` | adapter dependent | Schedules only fire while the app is running. iOS unsupported. |
| Health tracker | `arise/tracking.py`, `arise/fitness.py`, Java `StepTracker` | Manual entries + device step sensor; day/week/month/year reports; missing data shown as unavailable | `tests/test_tracking.py` | Physical activity | Only steps come from a device sensor; heart rate etc. are manual. |
| Habits | `arise/tracking.py` | Daily toggles, streaks, 30-day rates, weekly chart, reminders | `tests/test_tracking.py` | notifications | Reminders need the app running. |
| Money | `arise/tracking.py` | Integer minor units (exact), budgets, goals, monthly cash flow, CSV export | `tests/test_tracking.py` | none | Single currency label. |
| Finance | `arise/finance.py` | Yahoo/Stooq daily data with source+timestamp, SMA/EMA/RSI, volatility, drawdown, SMA backtest, alerts, paper trading with a risk limit | `tests/test_finance.py` | internet | Data sources are unofficial and untested from this build environment; no news analysis; **no live trading**. |
| AI assistant | `arise/ai.py`, `main.py` | Chat, explain/generate/modify/bugs/tests, data summaries; secrets redacted, rate limited; generated code goes to the editor as UNTESTED | `tests/test_security.py` | internet + your key | Quality depends on the model; nothing AI-written ever runs unapproved. |
| Voice, focus, auto-reply | `arise/voice.py`, `arise/focus.py`, Java `FocusService`, `AriseListener` | Unchanged from v0.1 | manual on device | microphone, accessibility, notification access, SMS/calls | Needs real-device testing. |
